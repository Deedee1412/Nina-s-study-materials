# Nina's studiemateriaal

De website: **https://deedee1412.github.io/Nina-s-study-materials/**

## Hoe het is ingedeeld

Elk vak heeft een eigen map. Alles van dat vak staat in die map.

```
index.html                         ← de startpagina met alle vakken
assets/                            ← de audiospeler (hier niets aan veranderen)
sociale-en-gedragswetenschappen/   ← één vak
    index.html                     ← overzicht van dit vak
    ... simpel uitgelegd.html      ← de uitlegpagina's
    Flashcards ... .html
    Vakfiche ... .html
    schemas ... .pdf
    audio/                         ← alle mp3's en audiogidsen van dit vak
```

## Een nieuw vak toevoegen (voor mama)

1. Maak op je computer een map met de naam van het vak, bijvoorbeeld `Geschiedenis`.
2. Zet daar alles in: het schema, de PDF's en de uitleg.
3. Zet de mp3's in een map `audio` binnen die vakmap.
4. Ga naar deze repo op GitHub en klik op **Add file** → **Upload files**.
5. Sleep de **hele vakmap** in het venster. De mappen blijven dan behouden.
6. Klik onderaan op **Commit changes**.
7. Stuur Yae een berichtje. Die maakt er een pagina van en zet het vak op de startpagina.

## Iets toevoegen aan een vak dat al bestaat

1. Open op GitHub de map van het vak (en eventueel de map `audio` daarin).
2. Klik op **Add file** → **Upload files**.
3. Sleep de bestanden erin en klik op **Commit changes**.

De bestanden komen dan meteen op de goede plek.

## Tips voor de audio

- Geef de mp3's een naam die begint met het bloknummer, zoals `Blok 4.1 Titel.mp3`.
- Een bestand vervangen: upload het opnieuw met **precies dezelfde naam**, in dezelfde map.
